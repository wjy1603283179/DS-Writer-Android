# Repository Instructions

1. Read `docs/INDEX.md` and `docs/DEVELOPMENT_PLAN.md`.
2. Select the current unchecked task, then read only the documents routed by the index.
3. Inspect the existing implementation before changing it.
4. Never implement from memory when project documentation defines the behavior.
5. If code and documentation conflict, resolve the inconsistency; record important decisions in `docs/DECISIONS.md`.
6. Run the documented checks and mark an item complete only after it works.
7. Update the owning document when architecture or behavior changes.
8. Never violate `docs/PURE_CONVERSATION.md`.
9. Keep engineering text and identifiers in English. All user-facing text must be Simplified Chinese.
